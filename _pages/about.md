======
我是计算机科学与技术专业的大三学生，兴趣集中在系统仿真与虚拟现实。从大一学 C 语言开始，我就对“用代码搭一个能交互的虚拟世界”这件事很好奇，后来陆续学了图形学、物理引擎和并行计算，也把这些知识用在了几个小型仿真项目里。我一直喜欢通过计算机模拟，去理解复杂系统到底是怎么运行的。

**专业基础**：我已经修读过数据结构、操作系统、计算机组成原理、计算机网络、数据库系统、软件工程、计算机图形学和数值分析等核心课程。编程语言方面学过 C++、Python 和 Java，能够使用 OpenGL 和 Unity 做三维可视化开发。在仿真项目里，我通常用 C++ 写底层计算模块，用 HTML 做数据分析和结果可视化。

**实践项目**：在 AnyLogic 上跟着教程完成了一些建模仿真案例，并用 Java 复现了其中几个；另外跟着教程写过一版还不太完整的渲染器，主要是想弄明白图形管线是怎么走通的。

**自我评估**：专业基础和基本的编程能力算是掌握了，但对 C++ 这类语言还不够熟练，也缺少从头到尾做完一个完整软件的经验，这是我目前最明显的短板。

**感兴趣的技术方向**：我最感兴趣的是基于代理的建模（ABM）和分布式仿真。我认为未来的仿真系统要支持更大规模、更高精度的场景，这离不开高性能计算和云原生技术的结合；同时我也在关注机器学习在仿真参数校准和不确定性量化中的应用。

**最希望学习的知识**：我想系统学习 MPI、CUDA 这类并行计算框架，以及分布式系统的设计，以便以后能处理百万级智能体的仿真任务；也打算在研究生阶段深入攻读仿真科学与技术方向，补上随机过程、偏微分方程数值解这些数学基础。

**未来三年规划**：未来三年我以考研为首要目标，计划报考国内系统仿真方向有优势的院校。大三结束前完成大创项目结题，并参加学科竞赛；大四全年集中复习数学和专业课。如果顺利升学，研究生阶段将深入钻研并行计算与数字孪生技术，并参与实际的工程仿真项目；如果考研失利，就先入职仿真相关企业积累开发经验，再寻找深造的机会。无论结果如何，我都会持续打牢编程和数学基础，围绕“模拟仿真”这个核心方向不断精进，最终目标是进入工业仿真软件研发或智慧城市数字化领域。
